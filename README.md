# Python for Foundation Year

A ready-to-use Python environment for the Engineering Foundation Year. Everything is set up for you: Python, the libraries, and the editor settings.

## Getting started

1. Click the green **Code** button at the top of this page.
2. Choose the **Codespaces** tab.
3. Click **Create codespace on main**.
4. Wait a minute or two while the environment builds. You'll see VS Code open in your browser.

## Running your code

- Create a file ending in `.py`, for example `hello.py`.
- Press the **play button** at the top right of the editor, or type `python hello.py` in the terminal.

## Plotting

Plots don't pop up in a window in Codespaces. Save the figure and open the image instead:

    import matplotlib.pyplot as plt

    plt.plot([1, 2, 3], [1, 4, 9])
    plt.savefig("plot.png")

Then click `plot.png` in the file explorer to view it.

numpy, matplotlib, scipy, pandas, sympy
